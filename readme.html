2. ELM327 / BLE Adapter Configuration

To communicate with the Yamaha RMAX via an ELM327 BLE dongle, send this initialization sequence to lock the baud rate, configure direct ECU addressing, and optimize buffer timing: 

// 1. Flush & Reset
AT D          // Restore Factory Defaults
AT Z          // Cold Reset (Wait 500ms for MCU reboot)

// 2. Formatting & Optimization
AT E0         // Echo Off
AT L0         // Linefeeds Off
AT S0         // Spaces Off (Produces contiguous hex output)
AT H0         // Headers Off
AT AT 2       // Adaptive Timing Level 2 (Aggressive, prevents timeouts)
AT ST FF      // Maximum Internal ELM327 Timeout

// 3. Yamaha Protocol & Physical Addressing
AT SP 6       // Set Protocol to ISO 15765-4 CAN (11-bit ID, 500 kbaud)
AT SH 7E0     // Set Transmit Header to 7E0 (Direct Engine ECU Address)

3. ISO-TP Multi-Frame Defragmentation

When you query 21 01, the Yamaha ECU returns a 26-byte payload. Because standard CAN frames hold a maximum of 8 bytes, the ELM327 delivers the response formatted into ISO-TP consecutive multi-frame lines: 

// Raw multi-frame response from Yamaha ECU:
01A 0:610104F90004 1:2300C522052100 2:0200CF75396C00 3:C18082048000AA

// Frame Breakdown:
01A               -> PCI Length (0x1A = 26 Bytes Total Payload)
0: 61 01 04 F9 00 04  -> First Frame (Service 0x61, LID 0x01 + First 4 Bytes)
1: 23 00 C5 22 05 21 00 -> Consecutive Frame 1 (7 Bytes)
2: 02 00 CF 75 39 6C 00 -> Consecutive Frame 2 (7 Bytes)
3: C1 80 82 04 80 00 AA -> Consecutive Frame 3 (7 Bytes)

Defragmentation Logic (JavaScript)

function defragmentISOTP(rawResponse) {
  let hexStream = '';
  const lines = rawResponse.split(/[\r\n]+/);
  
  for (const line of lines) {
    const clean = line.replace(/\s+/g, '');
    const match = clean.match(/^[0-9A-Fa-f]:([0-9A-Fa-f]+)$/);
    if (match && match[1]) {
      hexStream += match[1];
    }
  }
  
  // Extract 26 bytes following the 6101 response header
  const payloadHex = hexStream.substring(hexStream.indexOf("6101") + 4);
  const bytes = [];
  for (let i = 0; i < payloadHex.length; i += 2) {
    bytes.push(parseInt(payloadHex.substr(i, 2), 16));
  }
  return bytes; // Returns Array[0..25]
}

6. Delta-Testing Reverse Engineering Methodology

To discover and verify unknown byte offsets on any powersports vehicle:

  1. Isolate One Variable at a Time: Keep the vehicle stationary and change only one input (e.g. step on the gas pedal with engine off, pull the handbrake, or shift one gear).
  2. Sample at Constant Rate: Capture consecutive frames at 5–10 FPS using the Flight Recorder.
  3. Run Variance Analysis: Calculate $\Delta = \text{Max} - \text{Min}$ across all byte offsets. Any byte with $\Delta = 0$ is static; bytes with $\Delta > 0$ correlate directly with your action.
  4. Normalize Scale: Use the minimum observed byte value as 0% and maximum observed byte value as 100%:
    Percentage = ((RawByte - MinValue) / (MaxValue - MinValue)) * 100
